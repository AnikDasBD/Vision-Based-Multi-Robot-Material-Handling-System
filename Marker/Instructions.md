# Marker Instructions

* Run the marker print code for as many as needed. The marker print file is self-sufficient; `config.py` is not required.
* Change the marker size or marker IDs as needed, then physically print those markers.
* Normal 80 GSM paper is enough, but high-quality matte paper will definitely be better.
* We assigned **3.5 × 3.5 in** for the drop zone and car zones, **2.5 × 2.5 in** for robot markers, and **1.5 × 1.5 in** for objects.
* To test if markers are actually detected, run the `heading_test.py` file. For this, `config.py` is needed, which is available in the `server` folder.
* `heading_test.py` has no effect on the actual server code; it is merely a debugging tool.
* If there are issues regarding marker detection, the markers should be reprinted with increased physical dimensions.
* PowerPoint could be used for easily resizing the marker to the desired dimension and setting the printing paper size. Other software or online tools such as Illustrator/Canva can also be used.
