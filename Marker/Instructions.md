Run the marker print code for as many as many as needed. Marker print file is self sufficient, config file is not required. Change Library size, or marker ids as needed. 
Then Physically print those markers. Normal 80 gsm paper is enough. But high quality matte paper will definitely be better. We assigned 3.5 in * 3.5 in for drop zone, car zones, 2.5*2.5 sq in for robot markers and 1.5*1.5 sq in for objects. 
To test if markers are actually deteted, run the heading test file. but for this config file is needed, which is available in the server folder.
Heading_test.py has no effect on actual server code; it is merely a debugging tool. 
If there is issues regarding marker detection, then markers should be reprinted with increased physical dimensions.
Powerpoint could be used for easily resizing  marker to desired dimension and setting printing paper size. Other softwares or online tools such as Illustrator/Canva can be used. For saving AI Credits.
